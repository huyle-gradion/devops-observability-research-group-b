How this is measured (experimental)

Navigation Timing exposes one PerformanceNavigationTiming entry for this document load. Resource Timing exposes a PerformanceResourceTiming entry per fetched resource; the same-origin /test response's Server-Timing header is visible in the DevTools Network panel (Timing tab) and is read back here as PerformanceResourceTiming.serverTiming. A PerformanceObserver pushes largest-contentful-paint, layout-shift and event-timing entries as they occur, which web-vitals turns into a real value with a unit and a measurement id.

Lab vs field: the DevTools Performance panel and Trace Viewer replay one reproducible session (lab), whereas real-user monitoring aggregates many real users' sessions (field). CrUX is aggregated field data over many real users behind a public origin. This page is one controlled local demo session, so it is neither a production RUM cohort nor a CrUX population statistic.
